# Inertia Ed School Portal Demo, half-term edition

Updates
- Year planner uses 4 terms, split into halves
- Click a half-term to see available kits in a right panel, add with one click
- Availability view grouped by terms
- Kit images are supported via `imageUrl` on each kit
- Ratings and teacher feedback stored locally, open a kit to view and add comments

Brand colours
Open `styles.css` and set `--brand` and friends to your palette.

Blocks
We approximate half-terms as 5 weeks. Seeded for 2025 and 2026.
